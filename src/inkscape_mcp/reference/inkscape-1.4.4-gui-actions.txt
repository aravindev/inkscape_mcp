# Inkscape 1.4.4 GUI-only actions (D-Bus window and document scope)

`inkscape --action-list` (resource://inkscape/cli-actions) lists app-scope actions only.
A running Inkscape exports two more action groups over D-Bus, listed here. Captured from
Inkscape 1.4.4 on Linux with one document open. Re-check a live session with
`inkscape_live(operation="list_actions", target="<substring>")`: its `window` and
`document` keys come from the running GUI.

`inkscape_live(operation="apply_action", target=<name>, payload=<arg>)` finds the scope on
its own: app first, then window, then document. Document actions need exactly one open
document. An action that takes a parameter needs `payload` (string, integer, or number as
noted); every other action takes none.

On Windows and macOS the live bridge currently reaches window scope through the document
object, so the window-only actions below may be unavailable there.
